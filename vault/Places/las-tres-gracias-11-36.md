# Las 3 Gracias (11-36)

## Description

Las Tres Gracias was excavated in 2001 under archaeologist Fabricio Valdivieso. A 2002 CONCULTURA report is titled *Resumen de excavaciones arqueológicas en las Tres Gracias, Izalco, Sonsonate*, confirming that excavation took place, but the report remains unpublished and has not been located in the accessible corpus. The public bibliography and project documentation do not state which structures, deposits, or artifacts were recovered, so this page cannot yet provide an assemblage without speculation. [[Papers/atalaya-acajutla#Page 51|Source: PDF p. 51, bibliography]] [Valdivieso project portfolio, 2001 excavation caption](https://www.blueprintededucation.com/una-vida-dedicada-a-la-arqueologiacutea.html)

Two 2025 [[Organizations/ministerio-de-cultura|Ministry of Culture]] resolutions independently identify it as registered archaeological site 11-36 but likewise do not describe its contents. [Resolution DA-127-2025, PDF pp. 50–51](https://www.transparencia.gob.sv/descarga_archivo.php?id=NjI5ODQ3) [Resolution DA-136-2025, PDF pp. 74–75](https://www.transparencia.gob.sv/descarga_archivo.php?id=NjI5ODQ3)
