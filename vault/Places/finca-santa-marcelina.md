# Finca Santa Marcelina

## Description

Reconnaissance and twenty-two units identified pre-Hispanic foundations and a 3,701.5 m² reserve. Ceramics suggested Late Classic residential occupation. [[Papers/2010-torres-arqueologia-salvador-1992-2007#Page 116|Source: PDF p. 116–117]]
