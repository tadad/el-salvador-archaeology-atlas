# Salinas del Potrero find area

## Description

Water-line excavation exposed vessels, an incensario, shell, obsidian, and fragmentary human bone. Follow-up work provisionally interpreted a Preclassic burial with offerings. [[Papers/2010-torres-arqueologia-salvador-1992-2007#Page 136|Source: PDF p. 136–137]]
