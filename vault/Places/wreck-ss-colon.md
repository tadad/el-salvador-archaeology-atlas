# SS Colón

## Description

A registered steamship wreck at Acajutla, Sonsonate. Built in 1872 and wrecked in 1904. The inventory identifies a steamship wreck but does not describe its surviving remains. [[Papers/anales-53#Page 16|Source: PDF pp. 16–17, Figures 1–2]]
