# Local OCR Language Models

These `tessdata_fast` models are retained locally so the PDF conversion is
reproducible without changing the workstation's global Tesseract installation.

- Source: <https://github.com/tesseract-ocr/tessdata_fast>
- Upstream project: <https://github.com/tesseract-ocr/tesseract>
- License: Apache License 2.0

The main corpus pass uses Spanish plus English. French, German, and Swedish are
used selectively for early works published in those languages.
